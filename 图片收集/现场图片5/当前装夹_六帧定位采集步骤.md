# 当前装夹：恢复XY参数后采六帧定位

13:03的无出光复核符合预期：居中图的痕迹中心约(958.8,600.5)像素，距画面中心约1.2像素；返回图约(1133.5,829.0)像素，距原落点候选约1.4像素。这只核对了补偿方向和回位，不是加工精度验收。

两次演练归档仍记录11月9日的默认XY标定，本次分析使用的是已校验的12:10落点来源中的11月12日新参数。原始记录保留，不改写；两次演练不需要重拍。正式采新定位数据前，先按以下步骤恢复参数。

## 1. 一次性准备

1. 保持当前表盘装夹、相机、镜头和工作距离不变，保持激光关光，不操作C/Z。
2. 打开“分段圆环定位”，右侧选择“激光补偿（预览）”。
3. 点击“导入激光落点JSON”，选择 `单点试打_20261113_121007417\激光落点_预览标定.json`。该JSON须与原始trial.json及前后BMP同级。
4. 点击 **“新建记录并采用来源XY标定”**。它会清空当前定位表格，保留已导入的落点候选，采用正确相机XY参数；不会恢复旧工件圆心或方向。已有需要保留的定位记录先保存。
5. 在“标定参数”页核对：Jxx=584.955766、Jxy=-51.496990、Jyx=51.553807、Jyy=585.078517；图像1920×1200。
6. 连接数控并打开相机。在“采图／手动工具”中勾选 **“拍照时读取XYZ（已与面板MCS核对）”**，不要勾选“旋转采图”。C填写当前面板实际值，本次保持不动时应约为254.8241°。
7. 曝光、照明以能清楚看到孔缘和圆环为准；一次固定后，六帧使用同一设置。不要为了亮度改变相机或镜头高度。

## 2. 只移动XY，采同一次装夹的六张图

机床移动由现场面板操作；软件“停稳拍照并登记”只读坐标、拍照和归档，不移动轴。不要把昨天的绝对孔位当成当前装夹的定位结果。

| 照片名称 | 画面要求 | 用途选择 |
| --- | --- | --- |
| 参考1点 | 按工件钟点方向找到1点小孔，整个孔和外围亮边进入画面 | 1点参考孔 |
| 圆环12点 | 表盘本身的大圆环边缘，位置接近12点；不要求精确角度 | 圆环 |
| 圆环3点 | 同一大圆环的3点附近弧段 | 圆环 |
| 圆环6点 | 同一大圆环的6点附近弧段 | 圆环 |
| 圆环9点 | 同一大圆环的9点附近弧段 | 圆环 |
| 参考11点 | 与参考1点围住12点方向的11点小孔，完整孔及外围亮边进入画面 | 11点参考孔 |

建议从容易找到的1点参考孔开始。四张圆环图要分布在整圈四个方向，不能把同一局部的四张图当作四个方位；拍表盘圆环，不拍夹具圆边。

每到一处，先停止XY运动；填写方位名称并选好“用途”，点击“停稳拍照并登记”，将BMP保存在同一个新文件夹，例如“当前装夹_定位”。程序自动保存原图、单帧JSON及整组自动记录。

六帧过程中不重新装夹、不旋转C、不调整Z或光学高度。1点/11点用途由工件方向指定，不能由对称孔组自动区分唯一12点。

## 3. 保存并计算预览

1. 六张都完成后，点击“保存采图记录”，保存整组JSON。
2. 点击“自动定位并预览18孔”。检查黄色孔心是否落在11点/1点小孔中心、蓝色12点方向是否位于两孔之间。
3. 在右侧“激光补偿（预览）”核对光学条件后勾选一致，点击“计算18孔补偿预览”，再保存补偿预览JSON。
4. 将新文件夹中的全部BMP、单帧JSON、整组JSON和预览报告复制到“现场图片5”。

如自动识别报错，保留原图和记录，直接提供报错；不要为了通过预览改动原始采图坐标、放宽阈值或重复出光。

此阶段只定位、计算和保存预览，不执行18孔加工。新的工件圆心/方向必须来自本次装夹；本次落点补偿仍是未经加工精度验收的候选。
