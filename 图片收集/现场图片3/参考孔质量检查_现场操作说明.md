# 参考孔质量检查：本轮现场操作

本轮更新使用已有照片离线验证，不需要移动机床或出光。保留当前装夹、C/Z和相机高度。

## 更新程序

编译输出目录：`D:\zhiyouproject\hummingbird\src\Hummingbird.App\bin\Debug\net10.0-windows`。

复制更新的编译文件到现场运行目录。至少配套更新Hummingbird.App、Hummingbird.Core、Hummingbird.Vision的程序/DLL；保留现场config.json、原标定数据和照片。没有制作安装包。

## 使用现有照片验证

1. 打开“分段圆环定位”→“定位预览”。
2. 点击“导入采图记录JSON”，选择“参考孔质量_离线复核.json”。该文件与八张BMP保持同一目录；它只整理现有图片和配套信息，不是新的圆环定位输入。
3. 在表格里依次选中“XY复核_1点首次”“XY复核_1点返回”“独立核对_1点返回”，每张点击“检查当前图参考孔”。右侧自动切到“孔心检查”，显示黄色椭圆/十字、有效阈值支持数、阈值敏感性和质量提示。
4. 选中“独立核对_5点”，点击检查。预期明确拒绝输出孔心，并说明同一候选最多只有2个有效阈值支持，当前至少需要3个。不要降低条件强行输出中心。
5. 可继续检查“参考11点”“XY复核_11点”和“独立核对_7点”。这些图可以检出，但仍有明显的阈值敏感性预警。
6. 点击“保存孔心检查JSON”，另存结果并将右侧“孔心检查”界面截图放入现场图片3。

本操作只检查所选照片，不改变现有圆心、方向和18孔坐标。此复核组不要点击“自动定位并预览18孔”；原来的六帧定位输入仍为“保存采图记录（圆环+孔）.json”。

## 本组预期结果

| 图像 | 结果 | 孔心阈值敏感性 |
|---|---|---:|
| XY复核_1点首次 | 检出 | 约17.8µm |
| XY复核_1点返回 | 检出 | 约18.3µm |
| 独立核对_1点返回 | 检出 | 约18.6µm |
| 参考11点 | 检出，仍预警 | 约50.1µm |
| XY复核_11点 | 检出，仍预警 | 约50.6µm |
| 独立核对_7点 | 检出，仍预警 | 约31.4µm |
| 独立核对_5点 | 拒绝输出 | 有效阈值支持不足 |

同一1点孔首次/返回的识别中心差由旧算法约3.36像素降为约0.61像素。该比较是图像检测一致性，并非机床重复定位精度，也不是加工误差。

图像预警值10µm只用于提示识别稳定性，不是客户加工公差。通过试验筛选不等于加工精度合格。18孔CAD尺寸、机床坐标和激光落点补偿均未按现有孔的制造偏差修改。
