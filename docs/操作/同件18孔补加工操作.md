## 现场操作

1. 自行编译App，关闭旧程序后复制完整输出，保留现场config、操作状态及原始资料。标题核对 **v1.3.1**，不需要新ZIP，也不需要重传或修改原HM_MASTER。
2. 同一件回装到固定夹具，按原要求确认机床参考有效、工作Z/C和光学条件适用，连接设备。加工参数确认**每孔60秒、功率原始4420**；若修改过参数，先“应用当前参数（不出光）”并核对读回。不要将12%换算成1200。
3. 进入 **定位采集 → 整件联接 → 准备补加工**。当前若显示刚完成的原件，程序默认使用该轮记录；否则会要求选择原轮次的 **run.json**，位置为原工件目录下的`整件_6c6b896ad7b745a1a068317702e4ff72/run.json`。也支持原根目录“本件真实加工记录.json”或完整本件资料里的`整件/run.json`。不选择trial、定位检查或落点JSON。
4. 只建立补加工记录，不立即运动或出光。新目录名为`补加工_6c6b896a_时间`，界面应显示**追加60秒/孔、原始功率4420、累计请求120秒/孔**，开始按钮变为 **开始18孔补加工**。若参数与计划不符，请先设置本轮参数，再重新准备；准备不会向激光写参数。
5. 重新确认本次装夹。在机床面板从头启动原HM_MASTER，软件核对本次主控及路径，点击“检查整件就绪（不运动）”，确认显示的是本轮追加参数，再点 **开始18孔补加工**。
6. 程序自动重新采六处，计算本次回装位姿及18孔补偿，并核对18孔几何与原轮次一致，再逐孔追加加工。无需人工移动到18个旧坐标，也不需要为此重做光学或激光落点标定。

## 记录与限制

原run、trial、图片和manifest不覆盖。新轮次记录ParentRunId、PhysicalWorkpieceId、补加工轮次、本轮追加量及累计请求量。开始真实运行前，原归档旁新增`本轮补加工登记.json`，新工件目录创建原有真实加工占用记录，防止同一来源反复启动或同一补加工目录双击重跑。建立计划时不登记来源、不占用加工轮次；只有实际开始时才登记。

每轮结束仍自动保存独立本件资料，包含本轮六图、逐孔前后图/状态、补加工计划及前轮来源指纹。准备及恢复计划不自动连接设备、确认装夹或出光。断电/异常后不自动续跑或重打不确定孔，不能删除占用或登记文件绕过检查。若又需一轮追加，应在本轮完整完成、核对实物后，以最新完成的补加工记录作为来源。

本功能当前只支持“前轮全18孔完整完成后，同件全18孔追加”，不支持从未完成或存在不确定孔的轮次自动补齐，也不支持任意选部分孔。每轮仍执行原定位、边界、固定Z/C、关光及参数一致性检查。回装后若定位未通过，会停止并保存诊断，不使用旧孔位直接出光。

补加工软件已通过隔离模拟和界面检查，尚未代替用户执行本轮真实追加。最终孔径、孔深及崩边仍需实物验收。
