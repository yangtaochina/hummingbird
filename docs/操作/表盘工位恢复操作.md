# 表盘工位恢复（飞秒创芯v1.4.1，2026-11-17）

机床可以加工其他工件，切回表盘时恢复保存的工位。正常移动X/Y/C或MZ1不要求重新标定；机床参考有效、夹具和镜头/调焦未变、光学工作位置恢复后，沿用现有标定，每块新表盘自动六处采图，计算本件18孔位置。

## 本次确认的顺序

1. MCS MZ1退到 **-192.17803mm**。
2. 在该高度把C恢复至 **254.8245°**。
3. XY恢复到采图1点：**X=-135.02745，Y=-188.57564mm**。
4. MZ1恢复工作高度 **-201.87324mm**。

用户已在本会话确认上述高度和顺序允许。C使用最短转角，XY与C分段运动，进给分别30mm/min、60°/min。MZ2不动。C=DC最短路径语义依据[Siemens编程手册](https://support.industry.siemens.com/cs/attachments/64919334/PG_0212_en_en-US.pdf)。不添加未知的厂家松夹/夹紧M代码；若机床要求这些动作，需按该机床的定义补充，不能猜测。

本版只从以下**已核定入口区域**恢复：MCS X[-160.4,-134.0]、Y[-209.6,-181.7]、MZ1[-201.87324,-192.17803]。软件和NC都会检查。其他加工结束在范围外时，机床人员先按现场安全路径送入该区域，本版不承诺从任意加工位置直接回位。后续可用机床人员确认的入口通道扩展配置。

## 更新后如何操作

自行编译App并复制完整配套输出，关闭旧程序再替换，保留现场config及记录。标题应为飞秒创芯v1.4.1。源码与编译输出的“机床程序”目录随带`工位恢复配置.json`和`HM_RETURN.MPF`，JSON由软件自动读取，不需要日常选择，不需要新的ZIP。主导航第2页为“工位恢复”，第3页也保留跳转入口。

1. 由机床人员确认本次参考/绝对位置有效、报警已解除，回位区清空。程序不能代替机床回参考点，也不复位急停或改编码器偏置。
2. 保留或载入原六图基准路线，连接数控、打开激光串口。进入**第2页：工位恢复**，软件已经读取已核定的回位参数。机床已有对应回位MPF时不需重新载入JSON、导出或上传；机床没有时，点“没有回位程序：前往上传”，使用配套`HM_RETURN.MPF`。通过本软件上传会命名为HM_CHECK_时间，按回读成功后显示的名称在面板选择。配置来源、维护更换及导出保留在“配置说明／维护”中。
3. 先结束其他NC；在MC面板选择**HM_RETURN**，从头按一次 **Cycle Start**。这一步只让NC等待软件请求，不立即移动。回位NC与原主控共用已经核定专用的R220～R229，不能同时运行。
4. 软件勾选“本次机床参考有效，回位区域已清空，MZ2保持条件已核对”，点**开始恢复表盘工位（不出光）**。软件读回关光、确认入口及NC配置一致并先保存记录，再提交一次回位。无需人工逐轴移动。
5. 看“工位恢复”页底部结果。成功必须同时满足本次NC完成编号、实际XYZ读回和NC读出的C完成快照；界面填回目标C，但不自动勾选装夹确认。当前仍没有持续的C轴OPC UA反馈，后续勾选本次装夹确认前核对面板C。
6. **换新表盘、新建工件**，确认装夹；在面板选择原 **HM_MASTER**，从头按一次Cycle Start，再按原整件流程检查就绪、开始加工。原主控不修改。程序自动六处采图、重新计算本件位姿并加工18孔，不沿用上一块表盘的绝对孔位。已加工的表盘不能作为新件全18孔重打。

同一份回位配置/NC可以重复使用，不必每次生成上传；配置变更后才需重新导出并替换NC。普通换新表盘而C/Z及工作条件没变时，可直接走原新工件流程，不必每件先退高回位。

## 停止、记录与MZ2

“停止工位恢复”请求NC在当前运动段结束后退出；不是立即制停。需要立即停止时使用机床面板的进给保持/急停，按现场规程处理。超时、通信失败或应答不明均不自动重发，不把“已写目标值”当作完成。

资料根目录会生成`工位恢复_时间_编号/工位恢复记录.json`及`回位程序_核对副本.MPF`。记录含配置、程序指纹、请求编号、前后位置、C来源及失败/停止请求，不包含连接凭据。失败时保留原记录，核对实际状态后重新从面板启动回位NC；不要修改R值跳过检查。

MZ1、MZ2是面板对不同Z向机床轴的标识，具体带动哪个部件须查本机轴定义/机械结构。本程序原Z读数对应MZ1，不能把MZ1目标套到MZ2。当前MZ2抄值-238.4721只是当前读数，尚不能证明它是历史光学基准。若MZ2也被其他加工移动，且影响相机或激光工作高度，须先核对该轴原工作位置，不能仅靠恢复MZ1就宣称全部光学位置已恢复。
