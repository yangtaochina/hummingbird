## 固定基准恢复与自动曝光（2026-11-15补充）

### 当前点XY微调

正常的小幅放置偏移只要特征完整入画，最终定位就会重新计算当前圆心和方向，不一定需要移动XY。需要把特征恢复到基准采图区域时，可使用新增的单点辅助闭环：

1. 打开同一固定夹具和光学条件下的完整六步基准记录。在面板将XY移到当前步骤附近，核对Z/C和装夹。
2. 在“复用采图路线”选择“导出当前点微调MPF”。它以**导出时当前实际位置**为微调起点，文件为`HM_MICRO.MPF`；换位置/步骤后需要重新导出。
3. 确认R200～R209可专用、与其他NC/PLC用途无冲突，审核程序后在面板启动。现有采图程序与本单点微调程序不能同时运行，先按现场流程结束或切换原程序。
4. 点击“微调XY并采图”。程序先选曝光，匹配基准局部图像，计算小幅修正；写目标、读回验证、最后提交序号，由NC执行。实际XYZ判稳后重新拍照并检查匹配；最多两次，目标到起点始终≤0.20mm。微调前后照片、实际坐标、参数和修正量保存在“XY微调_步骤_时间”。
5. 图像对齐后仍重新拟合实体圆边、保存当前坐标并执行原定位检查。匹配不唯一、偏移过大、无足够纹理或通信失败会停下，不盲目扩展搜索范围。完成后本单点NC退出，再继续下一步骤。

这不是六步自动连续运动入口，尚未真机联调。NC只执行XY，Z/C保持固定且不含激光指令；C没有反馈节点时仍为人工确认。“停止自动拍照”可以取消软件微调流程，但不代替机床面板的停止/急停。NC等待无指令约60秒后报错暂停，软件单次运动确认超时15秒。

### 已记录激光预设

程序已内置2026-11-13 12:10软件出光记录：**请求2000ms、功率原始3950、重频100kHz、Burst1、旧Excel协议内部功率/控制模式0**。6%保留为操作者备注，不进行比例换算；旧协议未读到的脉宽保持设备现值，不写入猜测值。此预设来源明确为该次软件出光记录，人工合格孔如采用其他参数，应替换对应预设，不能混称两者相同。

打开串口后程序自动按已知协议只读核对。当前设置与预设一致时，无需重新试参数；执行出光前后也自动读回。当前不同则点击“恢复已记录出光参数（不出光）”，程序在关光状态下恢复已知字段，并验证读回结果。恢复请求时长为2000ms，修改的有效请求时长会记住；连接、参数恢复、无出光演练均不自动触发出光。请求2000ms沿用历史软件控制含义，不代表硬件精确定时。

下一件“新工件”后，核对顶部确认、选择第1步，点击“启动到位自动拍照”，再由机床面板启动经过审核的路线。软件只读XYZ，当目标位置稳定后自动拍照、命名、归档并切到下一步。每个M0拍照完成后，仍由面板继续下一段。

参考圆边识别失败、Z/C不符或通信失败会暂停自动采图。先查看“检查与归档”，处理后选择当前步骤再启动；不要在软件尚未完成采图时提前继续机床。面板C手填时，自动检查中的C一致性只是确认值一致，不代表自动检测到实际C未动。

同一光学条件下会尝试平移上次参考圆面的框选作为初值，但新照片仍必须重新提取边界，通过筛选后才使用新圆心。范围失效时重新放大框选。
